## 👋 About me

Hey! I'm **Aleix**, a software development student interested in understanding how things work — from the code itself to the systems running it.

I'm currently studying **DAM (Multiplatform Application Development)** and gaining practical experience in **Quality Assurance (QA)**. I enjoy finding bugs, designing clear test cases, troubleshooting Linux systems and building small projects to learn new technologies.

- 🧪 **QA & testing:** test design and execution, integration testing, bug reproduction and result analysis.
- 💻 **Development:** learning programming fundamentals and building projects step by step.
- 🐧 **Linux & systems:** Fedora KDE, command-line tools, Docker and self-hosted services.
- 🏠 **Homelab:** experimenting with servers, containers, networking and virtual machines.
- 🎯 **Goal:** grow into a software engineer with strong development, automation and DevOps skills.

> I believe the best way to learn is to build something, test it, break it, and understand why it broke.
